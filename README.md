# FreshCart - Cross-platform Expo App

## Run locally
1. Extract the project ZIP.
2. Open the extracted `freshcart-cross-platform-expo` folder in VS Code.
3. Open Terminal in that folder.
4. Run `npm install`.
5. Run `npx expo start -c`.
6. Press `w` to open the web version, or scan the QR code with Expo Go.

## Features
- Responsive category navigation: left sidebar on wide screens and horizontal bar on small screens.
- Category selection follows the scroll position.
- Search products.
- Add/remove products using + and − buttons.
- Cart state managed with React Context API.
- Cart count and total price.

The product data is sample data and can be replaced with the exact items from your Figma design.
